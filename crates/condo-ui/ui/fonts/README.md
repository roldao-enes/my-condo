# DM Sans

The app's typeface, as in the web version. Static TrueType instances (Light 300, Regular 400,
SemiBold 600, Bold 700), embedded in the executable by Slint.

* Source: https://github.com/googlefonts/dm-fonts, `Sans/fonts/ttf/` (files unmodified).
* Licence: SIL Open Font License 1.1, see `OFL.txt`. It allows bundling and redistribution with
  software; the font may not be sold on its own.
* Slint cannot load `woff2`, which is why the web app's copies are not used.
